# Portfolio

Portfólio profissional apresentando projetos, serviços de desenvolvimento web e formas de contato, com foco em conversão e experiência do usuário.

## 🔗 Demo
https://matheusmnttiii.github.io/Portfolio/

## 💻 Tecnologias
- HTML
- CSS
- JavaScript

## ✨ Funcionalidades
- Layout responsivo (mobile-first)
- Seções de projetos com links para demo e código
- Integração com WhatsApp para contato rápido
- Alternância de tema claro/escuro

## 📚 Aprendizados
Este projeto reforçou organização de layout, responsividade, manipulação do DOM e estruturação de uma página profissional voltada para apresentação de serviços.
